# Three Shape V2.9：原生 BNB 结算

本次依据用户要求，将购星及 LP 资金从 USDT 改为原生 BNB。此前 USDT 测试网部署保留为历史记录，不可升级，也不再作为当前接入目标。

## 价格与资金

- Star 起价 0.01 BNB；每累计售出 1,000 枚上涨 0.005 BNB。
- 总销售上限 100,000 枚，每钱包累计最多购买 6 枚。最后价格区间为 0.505 BNB。
- 跨价格档购买逐枚累加，使用整数 wei 计算。全部售出的理论总收入为 25,750 BNB；这不是预测或收益承诺。
- 支付方式为 `buyStars(quantity, maxPayment)` 的 `msg.value`。必须精确等于执行时的报价；超过用户确认的 maxPayment 或支付不符均整笔回滚。没有 USDT 授权，也不自动加价或追加付款。
- 支付款 80% 进入 Reserve，20% 进入用户指定 Treasury。任意资金转送失败均回滚购星、NFT 与计数。
- Treasury：`0x19a00449a5af7a51279b401dfe3bf92cb90a2751`。

## BNB 加池

- 交易对为 3SHAPE/WBNB。用户支付原生 BNB，路由通过 `addLiquidityETH` 包装成 WBNB 加池；不要求用户预先包装。
- 首次加池按每 1,430 万 3SHAPE 对应 0.008 BNB，LP 凭证送往销毁地址。
- 后续加池按链上储备比率计算；本笔每枚 Star 最多解锁 1,430 万 Token LP 铸币额度。未用额度立即过期，未用 BNB 留在 Reserve。
- 购星与 LP 是独立结果：LP 尝试失败会产生 LPAttemptFailed，已经成功购星仍有效；前端和 Agent 必须分别说明。
- 售罄后，待最后一次 LP 尝试结束，可由任何人调用 Reserve.settleToTreasury()，把剩余 BNB 全部转给固定 T。最后 LP 失败的余额也纳入最终结算；T 拒收则资金留存，允许重试。该结算是独立交易，不自动附加于最后购星。当前已发布旧测试网地址不支持此新增入口，新版需重新部署。
- 不新增管理员提币、铸币、锁仓或主网部署能力。此前用户接受的首次加池储备污染限制仍然存在，未做额外规则修改。

## 保留的游戏规则

免费领取、挑战销毁、继续、领奖、购星五步均验证当前钱包的 Agent ID 持有量。三档独立销毁 3/6/9 枚 NFT，普通水果至少一枚且必须同种；第二、三档至少包含 1/3 枚 Star，第一档也可用 Star 补齐。奖励、55,000 份全局份额、十阶段分配、Token 铸币上限保持原规则。

销毁不预留奖励份额。每钱包仅领取一档，继续不兑现旧档奖励。第三档奖励确认领取或累计购买六枚 Star 后关闭购星入口，是 UI/Agent 展示规则，未增加合约禁令。
